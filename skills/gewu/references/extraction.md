# 单篇论文结构化提取

## 元数据

核验 DOI、题名、作者、年份、来源、URL、预印本或发表版；记录 `access_level=metadata|abstract|fulltext`（是实际查看层级）。不凭空填 DOI 或数据。

## 研究结构

按顺序抽取：
1. 作者研究的问题与工作背景（引言定位）。
2. 明确的假设与作者声称的贡献（区分作者主张与解析者推断）。
3. 数据：来源、样本、时空范围、排除条件、训练验证测试划分。
4. 方法：方程、模型选择、重要参数、训练协议与统计推断。
5. 验证：基线、消融、敏感性、不确定性、独立数据、评价指标。
6. 结果：主要规律、数值与条件、负结果、例外。
7. 讨论：证据能支持的机制、其他解释、适用范围和局限。

每个高影响结论绑定 `paper_id + locator + summary + source_part`。如果全文未查看，切勿使用具体 Methods/Results 定位；以 `abstract` 标注来源即可。短摘述不能孤立于上下文。

## 自查问题

是否有数据泄漏或评价口径变化？对照是否控制样本量、计算量或参数规模？结果是否只在某一地区或事件成立？没有验证的解释是否被误写成事实？
