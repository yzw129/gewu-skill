# 独立评估与冻结规则

## 三层审查

1. 结构检查：脚本检查 JSON 格式、唯一 ID、规则来源、证据层级、留出集污染、review 状态；不验证文献真伪。
2. 原文核查：研究人员核对题录、DOI、全文原文位置、结果及反例是否被正确解释；留存检查表。
3. 独立评估：用预先冻结的留出论文/问题，在不改规则的前提下比较 `base_llm` / `direct_retrieval` / `gewu_skill`。

## 最小指标

- 可定位证据率：经原文核实有充分支持且定位准确的主张数 / 被抽查主张数。
- 事实错误率：核查后认定错误的事实主张数 / 被核查事实主张数。
- 反例处理：有反例的规则是否说明条件差异和主结论影响（逐条记录，避免自创综合分）。
- 可操作性：提出的研究设计是否写明假设、数据、对照、评价、失败判据和可复现设置。

先锁定测试集、评价规则和评价人员。记录模型版本、Skill 提示词哈希、日期、原始回答、评分和修改历史。发现之前的遗漏时记录原问题位置、漏检原因、受影响结论及追加检验。

结构检查通过 ≠ 原文核查通过 ≠ 科研效果验证完成。
