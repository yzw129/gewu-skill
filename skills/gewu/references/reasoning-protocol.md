# 科研思维蒸馏协议（v0.4）

## 蒸馏对象

真正要提取的不是论文中“使用了哪种模型”，而是“作者为什么提出问题、采用某种方法、设计哪些对照，以及如何从实验支持科学结论”。

四类必须区分的产物：

1. **领域事实**：作者在其样本与条件下报告的观测、模型与结果。
2. **跨文献规律**：多个研究结果在明确条件下形成的模式，标注反例和不确定性。
3. **科研决策规则**：若某问题具有指定前提，应采取何种分析、实验或证据核验行动。
4. **新研究假设**：从上述材料推导的可证伪猜想，不能当成文献共识。

## 行动协议要求

每条规则应按以下结构组织：

- IF：触发条件与所需证据是什么？不满足时停止哪些推论？
- THEN：下一步要做什么？明确输入、输出和完成判据。
- BECAUSE：支持证据来自哪些真实论文、段落和结果？这是事实还是机制推断？
- EXCEPT：在什么实验条件、测量限制或反例下可能失效？
- CHECK：怎样用反例或对照实验证实/否定规则的价值？

研究行动至少覆盖以下六关：

1. **问题界定**：研究对象、预测/推断目标、时空尺度、已有工作与目标缺口。
2. **可辨识性**：观测是否足以区分不同潜在过程？有什么未测量未知量？
3. **假设设计**：写出竞争性解释和可能推翻核心假设的实验结果。
4. **实验协议**：数据来源和切分、基线及消融、混杂变量、指标、置信度/敏感性与复现配置。
5. **证据审查**：反面论文、异常个例、选择性报告、统计与因果推断限制。
6. **形成结论**：先给主要规律，再按事实→推断→假设分层陈述；说明失效范围。

## 生成门禁

v0.4 build 仅允许使用已经人工标记核查的 reviewed/tested 规则。脚本可以检查字段、引用和冻结状态，但无法代替专家核验文献内容。

当规则只支持某一研究领域，不能把它标为跨学科通用科研规律；跨领域迁移必须提供新问题的独立验证。项目提到“成长”时，须区分“知道更多”和“在未见任务表现更好”。
