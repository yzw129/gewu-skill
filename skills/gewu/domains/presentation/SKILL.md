# 学术汇报与演示文稿能力

## 学习目标

从优秀作品中学习：受众分析、时间/页数分配、主结论叙事、图表与文字比例、逐页信息密度、标题表达、视觉一致性和可编辑交付；不机械照搬视觉元素。

## 执行流程

1. 明确报告受众、时长、核心问题与允许引用的资料。
2. 组织“背景 → 科学问题 → 方法 → 证据 → 结论 → 决策”叙事，每页一个主要信息。
3. 对每页分别检查数据来源与图表一致性，避免将相关性图示画成因果关系。
4. 以受众可阅读的字号、对比、信息层级安排版式；有可编辑需求时输出可独立修改的文字和图形。
5. 真实渲染并逐页检查裁切、错位、字体、图表可读性；记录与原设计的差异。

## 评价

`claim_fidelity`、`narrative_clarity`、`visual_hierarchy`、`editability`。

独立对照需要用相同内容和模板，区分“换了数据”与“汇报技能更好”。单纯生成每页图片不算完成可编辑 PPT。
